# AWS-CloudOps-Labs
Hands-on AWS CloudOps labs — notes, screenshots, and scripts from my cloud learning journey.

This repository documents all the hands-on labs I complete as part of my 
AWS Cloud Operations learning journey. Each folder contains my notes, 
screenshots, commands used, and key takeaways from every lab.

## 🎯 Goal
Build practical, job-ready skills in AWS cloud operations — covering 
core services like IAM, EC2, S3, VPC, CloudWatch, and more.

## 🛠️ Topics Covered
- Identity & Access Management (IAM)
- Compute (EC2, Auto Scaling)
- Storage (S3, EBS, EFS)
- Networking (VPC, Subnets, Security Groups)
- Monitoring (CloudWatch, CloudTrail)
- And more as the course progresses...

## 📌 Why This Repo Exists
I believe in learning by doing. Every lab here is something I actually 
ran in AWS — not just theory. This is my public record of progress.
